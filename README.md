# EkskulHub

Website demo pendaftaran ekstrakurikuler SMA 1 Prestasi Bangsa.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` dengan browser modern.
3. Data disimpan di LocalStorage browser tersebut.

## Login admin demo
- Username: `admin`
- Password: `ekskulhub123`

## Catatan penting
- Jadwal, pembina, dan kuota adalah data contoh, bukan informasi resmi sekolah.
- Semua data anggota hanya berada di browser lokal dan tidak tersinkron antarperangkat.
- Password formulir tidak disimpan. Login admin berbasis JavaScript hanya simulasi dan tidak aman untuk produksi.
- Kartu PNG adalah kartu demo, bukan identitas resmi sekolah.
- Font Google dapat memerlukan koneksi internet; font fallback tetap tersedia.
